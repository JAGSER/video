# Стиль «Шаги»: пошаговый обучающий рилс

РЕЖИМ: ПАНЕЛЬ. Библиотека подключена: глобальная `STP`, заново не объявляй. Свои функции для редких предметов писать можно, в той же манере (белые карточки, синие папки, жёлтый акцент, шрифт Inter).

## Раскладка (главное)
- Ролик делится на **шаги**. Пока человек объясняет шаг, сверху тёмная панель (y 0…960), снизу сам человек: `layout(t)` = 1. Хук в начале (первые 3–8 с, пока человек обещает результат) и финал с призывом: человек на весь экран, `layout(t)` = 0.
- `function layout(t, k) { return STP.lay(t, PANEL); }` где `PANEL = [[начало, конец], …]` в секундах исходника. Переключай на границе фраз, не посреди слова.
- В режиме панели **первым делом** `STP.panel(g, k.split(t))`, потом всё остальное. Ниже y 960 в панели ничего не рисуй.
- Полоса y 780…900 внутри панели и y 1160…1260 на весь экран заняты субтитрами приложения: туда ничего не ставь.
- Размеры как в референсе: окна и таблицы почти во всю ширину (x 70, w 940, по умолчанию так), иконки программ 180–220 px, одиночная папка 240–280 px, подписи 34 px. Главная картинка занимает центр y 270…760, не мельчи.

## Панель шага
1. **Заголовок** `STP.header(g, lt, n, 'Название', {y: 190})`: «Шаг N.» жёлтым, название белым, 2–3 слова из речи (Подготовка, Инструменты, Стиль монтажа, Съёмка и монтаж). `lt` = секунды от начала шага: заголовок появляется один раз в начале шага и стоит весь шаг. Если в ролике нет нумерованных шагов, придумай смысловые разделы и нумеруй их сам; `n` можно опустить (`null`), тогда только название.
2. **Центр** y 270…740: одна главная картинка на фразу, меняется вместе со смыслом, точно на слово (`k.when`):
   - программа, сервис, нейросеть → `STP.claude` (только для Claude) или своя иконка: белая карточка с логотипом-буквой;
   - папка, файлы → `STP.folder`, структура папок → `STP.tree`, связь «одно с другим» → две иконки и `STP.dots`;
   - промпт, команда, текст в чат → `STP.prompt(g, lt, t0, 'текст промпта')` (печатается);
   - список программ, ссылок, тарифов → `STP.table`; выбор варианта → `STP.choice` (подсветка с галочкой на слове выбора);
   - стиль, шрифты → `STP.type`; ролики, примеры, референсы → `STP.reels`; проверка, раскадровка → `STP.board`; действие (нарезка, экспорт) → `STP.pill`.
   - «не так» → `STP.cross` поверх; клик → `STP.cursor` с `press`.
3. Тексты внутри карточек короткие и по-русски, взяты из речи (названия программ латиницей как пишутся). Никаких выдуманных цифр и ссылок, если их нет в речи; адрес сайта только если он назван.
4. Смена картинки: старая уходит за 0,2 с (`STP.life`), новая появляется `STP.rise`/`STP.pop` за 0,3 с. Между сменами минимум 1,5 с. Заголовок шага при этом не мигает.

## На весь экран (хук и финал)
- Хук: `STP.plate(g, ['Своя строка 1', 'строка 2'], 540, y, p)` белая плашка с чёрным текстом-обещанием ролика (2 строки до ~22 знаков), ставь ниже полосы субтитров (y 1330…1450) или над головой; пока плашка видна, она главная. Можно `STP.fan` 2–4 карточки веером над головой (y ≈ низ кадра не трогай), если место над головой свободно (`k.face`).
- Финал/призыв: `STP.word(g, 'СЛОВО', 540, y, p, {size: 130})` крупное бежевое слово (то, что человек просит написать в комментарии, или главное слово призыва) между подбородком и субтитрами: y = низ лица + 95, если до y 1150 хватает места, иначе y 1330; и снова `STP.plate` с названием ролика в последние 2 с.
- Лицо и глаза никогда не закрывай: проверяй `k.face(t)`.

## Звук
Голос главный. `s.play(t, имя, 0.08…0.16)`: появление карточки `pop_soft`, папки `wood`/`pop_high` по очереди с pitch 1.15 → 1 → 0.85, печать промпта `type` (раз на окно), выбор/галочка `click` или `toggle_on`, смена шага `marimba_run` (0.1), таблица строками `tick`, итог `success`. Никаких вжухов. 15–30 событий на минуту.

## API `STP`
**Время**: `pr(t,a,b)` `lerp` `eo` `eio` `eb` `stag(lt,t0,i,gap,d)` `life(lt,a,b,fi,fo)` (0…1 с появлением и уходом) · `lay(t,[[a,b]…])` · `at(t,[{t0,…}])` → `{i,s,lt,next}` текущая сцена.
**Основа**: `begin(t,k)` → g · `panel(g,s)` · `header(g,lt,n,title,{y,size,word})` · `rr` · `pop(g,x,y,p,fn)` · `rise(g,p,fn)` · `txt(g,s,x,y,size,{col,al,max,w:'m'|'b'})` · `label`.
**Иконки**: `folder(g,x,y,w,{label})` · `claude(g,x,y,s,{label})` · `dots(g,x1,y1,x2,y2,p)` · `check(g,x,y,s,p)` · `cross(g,x,y,w,p)` · `cursor(g,x,y,{press})` · `pill(g,x,y,'Нарезка',{icon:true})`.
**Карточки** (все сами появляются от `t0`): `win(g,x,y,w,h,{title,send,bar})` · `typed(g,s,x,y,w,lt,t0,{size,cps})` · `prompt(g,lt,t0,text,{x,y,w,h,title})` · `table(g,lt,t0,[{name,sub,link}],{title,y})` · `choice(g,lt,t0,{title,label,items,pick,tPick,y})` · `board(g,lt,t0,{n,times,labels,title})` · `reels(g,lt,t0,{n,w,y})` · `type(g,lt,t0,{big:'Aa',sub})` · `tree(g,lt,t0,'корень',['a','b','c'],{tk:[время каждой]})` · `person(g,x,y,w,h,seed)`.
**Весь экран**: `plate(g,lines,x,y,p,{size})` · `word(g,s,x,y,p,{size})` · `fan(g,lt,t0,['win','logo','reel','list'],{y,w})`.
Палитра `STP.P`: `yellow` акцент, `white` текст, `grey` подписи, `orange` Claude, `blue` папки, `card` белые карточки, `ink` текст в карточках, `link` ссылки.

## Каркас
```js
const W = (q, n, d) => k0.when(q, n, d); let k0;
const PANEL = [[6.2, 80.5]];
const STEPS = [{t0: 6.2, n: 1, title: 'Подготовка'}, {t0: 30.1, n: 2, title: 'Инструменты'}];
function layout(t, k) { return STP.lay(t, PANEL); }
function draw(t, k) {
  k0 = k; const g = STP.begin(t, k), s = k.split(t);
  if (s > 0) {
    STP.panel(g, s);
    const st = STP.at(t, STEPS); g.save(); g.globalAlpha *= s;
    if (st) STP.header(g, st.lt, st.s.n, st.s.title);
    const sc = STP.at(t, SCENES); if (sc) sc.s.fn(g, t, sc.lt, STP.life(t, sc.s.t0, sc.next, .01, .2));
    g.restore();
  } else { /* хук и финал на весь экран */ }
}
```
